# MAX → Telegram мост

Приложение пересылает сообщения из чатов мессенджера **MAX** (бот на
[maxapi](https://pypi.org/project/maxapi/)) в чаты **Telegram** (бот на
[aiogram](https://docs.aiogram.dev/)).

## Два режима работы

**Режим USER (рекомендуется для личного дублирования).** Приложение
подключается к вашему личному аккаунту MAX по WebSocket-протоколу веб-клиента
(web.max.ru) и видит **все** ваши диалоги: личные сообщения (в том числе от
людей, которые пишут вам впервые), групповые чаты и каналы — без добавления
какого-либо бота. Всё пересылается в Telegram автоматически.
⚠️ Это неофициальный протокол (reverse-engineering): нарушение пользовательского
соглашения MAX может привести к блокировке аккаунта — используйте на свой
страх и риск. Токен даёт полный доступ к аккаунту, храните `.env` в секрете.

Как получить креды: откройте https://web.max.ru, войдите, F12 → Application →
Local Storage → скопируйте поле `token` из ключа `__oneme_auth` (это
`MAX_USER_TOKEN`) и значение `__oneme_device_id` (`MAX_DEVICE_ID`). Режим
включается автоматически при наличии обеих переменных (или явно: `MAX_MODE=user`).

**Режим BOT (официальный).** MAX Bot API (@MasterBot, maxapi) доставляет
события только из диалогов, где состоит бот; личные сообщения вам он перехватить
не может. Подходит, если вы не хотите рисковать аккаунтом. Токен —
`MAX_BOT_TOKEN`, подробности и способы обхода ограничений — в [docs/FAQ.md](docs/FAQ.md).

## Возможности
* Дублирование ВСЕХ личных и групповых сообщений в user-режиме
  (`MAX_CHAT_IDS` — белый список, `MAX_EXCLUDE_CHAT_IDS` — исключения);
* Уведомления о подключении/потере связи и добор сообщений за время разрыва;
* Пересылка текста с сохранением упоминаний (`{{Ivanov}}` → HTML) и
  экранированием;
* Пересылка вложений: изображения, видео, файлы, стикеры, аудио;
* Заголовок вида `Имя Фамилия (@username) | Название чата` + тег
  `#forwarded_from_max`;
* Маппинг чатов `MAX → Telegram` (`CHAT_MAP`) или единый целевой чат
  (`TG_CHAT_ID`);
* Защита от повторной доставки (SQLite-таблица соответствий `bridge.db`)
  и фильтрация сообщений ботов;
* Корректное завершение по SIGINT/SIGTERM.

## Установка и запуск
```bash
pip install -r requirements.txt
cp .env.example .env   # заполнить токены и TG_CHAT_ID
python main.py
```

Бот MAX должен состоять в нужных чатах; токен получается через @MasterBot
в MAX, токен Telegram — через @BotFather. Бот Telegram должен быть добавлен
в целевой чат (для супергрупп id указывается со `-100`).

## Тесты
```bash
pytest tests/
```
29 тестов покрывают валидацию типов maxapi (recipient — экземпляр
`Recipient`, `timestamp` — int, `mid` — строго str, lowercase enum
вложений) и сквозную логику обработчика через моки sender/store.

## Структура
```
main.py               точка входа (цикл событий, graceful shutdown)
bridge/config.py      настройки из env/.env, маппинг чатов
bridge/max_listener.py слушатель MAX (Router + NotBotMessage фильтр)
bridge/convert.py     конвертация текста/вложений, скачивание файлов
bridge/tg_sender.py   отправка в Telegram (aiogram Bot)
bridge/user_client.py  WebSocket-клиент личного аккаунта MAX (user-режим)
bridge/user_listener.py слушатель user-режима: фильтрация, вложения, пересылка
bridge/store.py       SQLite-маппинг MAX msg id -> TG msg id
```
