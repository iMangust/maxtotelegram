# Частые вопросы (FAQ)

## Почему бот видит не все мои сообщения? Можно ли читать ВСЁ, без добавления бота в чаты?

**Коротко: нет, это невозможно ни через официальный API MAX, ни через наш мост.**
Это ограничение платформы, а не недоработка приложения.

### Как устроен API MAX (dev.max.ru)

MAX предоставляет только **Bot API** — то же самое, что Telegram Bot API:

1. Токен выдаётся конкретному **боту** (создаётся через @maxid / via.messapp),
   а не вашему личному аккаунту. Термин «токен сессии пользователя» из
   предыдущих обсуждений был неточным — пользовательских токенов-сессий
   публичный API MAX не имеет.
2. События (`message_created` и др.) приходят **только из тех диалогов,
   где бот состоит**:
   - личное сообщение человеку бот **не увидит никогда** — события
     прилетают только если пишут *самому боту*;
   - в групповой чат нужно **добавить бота** (один раз, на 5 секунд);
     после этого он получает все новые сообщения чата.
3. Ограничения long-polling по данным maxapi 1.2.3 / docs-api:
   ~2 запроса/сек, батч до 100 событий, TTL событий 24 часа — старые
   сообщения при простое бота теряются.

### Что происходит, если пишет «новый человек», с которым вы не общались

Такое сообщение приходит в ваш личный диалог в MAX, где нашего бота нет, —
и поэтому оно **не может быть переслано**. Как только вы ответите этому
человеку (или перешлёте ему любой контакт), вы можете добавить бота в диалог,
и дальнейшие сообщения уже будут дублироваться.

### Единственный легальный способ «пересылать всё»

Добавьте бота один раз во все чаты, которые вас интересуют. Дальше ничего
делать не нужно: новый человек, который напишет вам лично, останется зоной,
недоступной для Bot API любого мессенджера.

### А если использовать «userbot» (неофициальный клиент под вашим логином)?

Технически userbot читал бы все ваши диалоги, но:

- у MAX **нет публичного пользовательского API**; reverse-engineered клиенты
  нарушают условия использования сервиса;
- такие решения ломаются при каждом обновлении и часто приводят к
  **блокировке аккаунта**;
- поддерживать такой код в этом проекте мы не будем.

## Как добавить бота в чат MAX (30 секунд)

1. Откройте чат → «Информация о чате» → «Добавить администратора/участника».
2. Найдите вашего бота по username и добавьте его.
3. Готово: следующие сообщения из этого чата появятся в Telegram
   (команда `/chats` в Telegram показывает все чаты, откуда бот уже
   получает события).

## Уведомления о новых личных сообщениях

Пока человек пишет вам лично и бота в диалоге нет — уведомления не
приходят никак. Рекомендуем включить push-уведомления самого MAX для
личных сообщений, а дублирование в Telegram использовать для групповых
чатов и диалогов, где бота удалось добавить.
